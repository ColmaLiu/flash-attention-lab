# 实验记录模板

将本页复制到 `artifacts/notes/<lesson>.md` 后填写；个人实验结果不进入公共模板。

- 课程、输入 case、当前源代码指纹：
- 假设：改变什么，预期哪个瓶颈下降，什么结果会推翻它？
- 设计：数据 ownership、存储位置、依赖与同步、精度转换。
- 正确性：完整 case、首个失败坐标或报告位置；sanitizer 命令及结果。
- 比较：同一 shape/dtype/scale/mask 下的学生、完整答案、快速库；graph 与 eager 分列。
- 测量范围：分配、布局转换、输入生成、编译是否排除；采样数、分布、执行顺序。
- 解释：算法 IO 模型、实际 counters、源码解释、未验证假设分别写明。
- 反例与下一步：哪些 case 变慢；下一次只改变什么？

不要复制旧测量作为新源码的验收。源码或依赖改变后重新验证。
