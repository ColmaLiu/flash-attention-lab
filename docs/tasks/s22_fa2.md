# s22_fa2 · FA2 并行与 Tensor Core 融合

阶段 2。前置：[s12_online](s12_online.md)、[s21_pipeline](s21_pipeline.md)

先读：[从三个算子到流式 attention](../attention-math.md)，包含可手算的例子、状态合并推导及精度边界。

## 从两个 GEMM 到一个 attention 数据流

单独快速的 QK 和 PV 并不保证融合后快速：softmax 插在两者之间，P 的布局和精度还需要满足第二次矩阵乘。FA2 将 query 序列块加入并行维度，并调整 CTA 内工作分配以减少通信和非矩阵工作。少量 heads 的性能案例专门检查序列维并行是否有效。

为每个输出行确认唯一的最终拥有者，再追踪归一化统计和 O 的归属。跨 warp 的部分结果合并可能造成额外 shared-memory 访问；省掉无谓归一化也可能有明显价值。P 转成低精度供 Tensor Core 使用时，要单独报告这一转换的误差，不能用“FP32 accumulator”掩盖所有数值变化。

## 定义、代码与参考

数学结果仍是 scaled dot-product attention；Q/K/V/O 使用 FP16/BF16，LSE 为 FP32。

接口：`[B,N,H,D] → O 同 shape/dtype，LSE [B,H,N] FP32`。输入必须在同一 GPU 上连续存储。精确支持域是 [curriculum.json](../../curriculum.json) 中本关的 `domain`，测试例是采样而非 shape 白名单。所有维度为正；输入有限。

- 学生入口：[students/cuda/s22_fa2/kernel.cu](../../students/cuda/s22_fa2/kernel.cu)，host workspace 声明在同目录 `entry.py`。
- 完整可读答案：[solutions/s22_fa2/](../../solutions/s22_fa2/)。可以先独立实现，也可以阅读答案后做控制变量实验；学生入口不会调用答案。
- 独立数学 oracle：[reference.py](../../flash_attention_lab/reference.py) 的 `mathematical_reference`；attention 使用 FP64 的直接数学定义，并按独立 query 行限制临时内存。
- 快速库基线：强制 cuDNN fused attention，返回 O+LSE；拒绝静默回退到数学实现。

源码阅读：[kernel.cu](../../solutions/s22_fa2/kernel.cu) 与 [fa2_optimized.cuh](../../solutions/s22_fa2/fa2_optimized.cuh) 中的 `mma.sync`、`ldmatrix` 和 `cp.async`，再对照 FA2 论文 §3 的工作划分。 固定版本与官方链接见 [sources](../sources.md)，本地答案的设备源码入口见 [参考实现与源码](../reference-implementations.md)。

## 实验与完成标准

与同输入 cuDNN O+LSE 比较；保留 dtype/结构消融，不能把全部收益归因于 FA2。

核对 query grid、CTA 内输出 ownership、跨 warp 通信及非矩阵工作；标明 P 的精度转换。

完成标准包含三项：全关数值/stream/重复调用检查通过；相关 memcheck/racecheck/synccheck 无问题；提交源码与设计证据，以及相同输入下答案、学生、快速库的计时。用源码确认目标机制，再用各个 perf case 的实测差距确定下一步优化。

```bash
./lab task s22_fa2 -v
./lab reference s22_fa2 --case 0
./lab solution s22_fa2 --case 0
./lab check s22_fa2 --case 0
./lab check s22_fa2
./lab bench s22_fa2 --case 0
./lab sanitize s22_fa2 --tool memcheck --case 0
```

先运行小例，再选择表中 perf 案例比较速度；不要把 debug 微小输入的 launch 时间当成吞吐。计时范围、graph/eager 与不等价比较见 [benchmarking](../benchmarking.md)。把观察记入忽略目录，使用 [实验模板](../../experiments/README.md)。
